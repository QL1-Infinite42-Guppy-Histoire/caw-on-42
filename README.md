# CAW on 42

A standalone record page for the community plan to run CAW on 42 Chain: a new,
community-led CawActions on 42 Chain, free same-name claims for existing QL1
name holders, one action ledger on 42 with QL1 kept as the historical record,
and a token design that is still in discussion.

**Live site:** https://ql1-infinite42-guppy-histoire.github.io/caw-on-42/

## Status

Planning / discussion stage — **nothing has launched**. There is no contract
to use yet and no date has been promised. This page records the public
discussion held in the QL1 CAW SocialFi Telegram group on Nov 14–15, 2026,
and the current shape of the plan.

## Notes

- Single static page (`index.html`), no build step, no external dependencies.
- English by default, with an in-page Japanese toggle.
- White (light) theme by default, with a dark toggle using the shared
  `guppy-theme` localStorage key, per the Guppy's Guide UI spec.
- Developed by the community. Not an official site.
- By decision, this page is not listed on the Guppy's Guide dashboard or the
  links hub.
